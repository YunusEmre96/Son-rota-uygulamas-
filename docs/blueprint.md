# **App Name**: RotaBul

## Core Features:

- Map Display: Display a full-screen Leaflet map using OpenStreetMap.
- Start Point Selection: Record the coordinates of the first click as the starting point and add a marker.
- End Point Selection: Record the coordinates of the second click as the end point and add a marker.
- Route Calculation: Use Leaflet Routing Machine to calculate and display a route between the start and end points, following roads.
- Directions Panel: Display the directions panel with step-by-step instructions on the map.
- Reset Logic: Clear existing routes and markers on subsequent clicks, starting a new route.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to reflect openness and exploration, fitting for a mapping application.
- Background color: Light gray (#F0F0F0) providing a neutral backdrop that ensures map details stand out.
- Accent color: Soft green (#90EE90) to highlight interactive elements such as markers and route lines.
- Font: 'PT Sans', a humanist sans-serif, will be used for both headlines and body text. It combines a modern look with a little warmth or personality.
- Simple, clear icons for markers and direction indicators, ensuring ease of understanding.
- Full-screen map display with a clean, minimal interface to focus on the routing information.
- Smooth transitions when displaying the route and updating the direction panel for a seamless user experience.
